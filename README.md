# BioGestión — demostración pública

Demostración exclusivamente con datos ficticios. No requiere credenciales, base de datos ni conexión Supabase.

Ejecutar localmente: `python -m pip install -r requirements.txt` y `python -m streamlit run app.py`.

Publicar SOLO el contenido de esta carpeta en un repositorio independiente de GitHub y desplegar en Streamlit Community Cloud con entrada `app.py`.

No subir la aplicación privada, copias de seguridad, credenciales ni datos de clientes.
